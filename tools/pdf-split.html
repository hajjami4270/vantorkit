Zero Server Transmission

Frequently Asked Questions

Clear answers to common questions regarding local PDF extraction, confidentiality, and page selection.

Is it safe to split sensitive tax or medical PDFs here?

Yes. Disconnect your computer from Wi-Fi or enable Airplane mode after loading the page, and the tool will continue working with 100% full capability. No network requests are ever dispatched.

How do I format custom page ranges?

Use commas and hyphens (e.g. 1-3, 5, 8-12). You can also simply click any page card in the interactive grid to toggle it on or off.

What happens when I choose "Split into Single Pages"?

The tool separates each page into an individual 1-page PDF document (e.g. page-1.pdf, page-2.pdf) and packs them into a single `.zip` file for quick downloading.

Are there any file size or page count limits?

No paywalls or arbitrary daily limits exist. You can split documents as large as your device's browser memory comfortably accommodates.
